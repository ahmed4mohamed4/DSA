<div align="center">
    <h1>Single linked list</h1>
</div>
<p style="text-align: justify; font-size: 20px;">
    linear data structure that consists of a sequence of nodes, where each node contains data and a reference (or link) to the next node in the sequence. It is called "single" because each node only points to the next node, unlike a doubly linked list where each node points to both the next and previous nodes.
</p>

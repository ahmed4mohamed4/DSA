# Polynomial Representation
it is collection of terms with a single variable and a coefficient. The terms are combined using addition and subtraction. The degree of a polynomial is the highest power of the variable in the polynomial.

<image src="./images/polynomial.png" alt="Polynomial Representation" width="400"/>

## Representation of Polynomial
- we store coefficients and exponential.

**p(x) = 3x^5 + 2x^4 + 5x^2 + 2x + 7**

| coefficient | exponential |
|-------------|-------------|
| 3           | 5           |
| 2           | 4           |
| 5           | 2           |
| 2           | 1           |
| 7           | 0           |
